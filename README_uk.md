MRU Layout 1.1.3
Перемикання розкладок за історією на Win + Space

ЗАПУСК
1. Всі файли мають бути в одній директорії
2. Запустіть Start.cmd подвійним кліком. Звичайних прав достатньо
   для роботи зі звичайними програмами. Не запускайте всередині ZIP.
3. Біля годинника (можливо, серед прихованих значків) з'явиться
   значок із підказкою "MRU Layout".
4. Перевірте роботу в Блокноті, а потім у своїх звичних програмах.

КЕРУВАННЯ
Win + Space, потім відпустити обидві клавіші:
перехід до попередньої використаної розкладки.

Утримувати Win, натиснути й відпустити Space двічі:
вибрати третю розкладку в історії. Відпустити Win для завершення.
Довго тримати Space не треба: автоповтор навмисно ігнорується.

Порядок фіксується після відпускання Win, а не після кожного
проміжного вибору. Жодна пара мов не зашита в код.
Вибір іншої мови звичайним індикатором Windows також враховується.

ПЕРШИЙ ЗАПУСК / ПОРОЖНЯ ІСТОРІЯ
Поки реальної MRU-історії ще немає, скрипт використовує природний порядок
розкладок Windows. Поточна розкладка стає початком цього циклу: наприклад,
для порядку 1, 2, 3 при активній 2 перше Win + Space вибере 3.
Після першого фактичного перемикання далі вже працює MRU-логіка.
Якщо Windows не віддає список розкладок через API, скрипт додатково читає
їхній порядок з профілю користувача; крайній резервний варіант - передати
це конкретне натискання стандартному перемикачу Windows.

ПРИКЛАД ПЕРЕВІРКИ
Після запуску виберіть мовою індикатора розкладку 1, потім 2.
Після кожного ручного вибору поверніться в Блокнот приблизно на секунду.
Натисніть і відпустіть Win + Space: має бути 1.
Натисніть і відпустіть Win + Space: має бути 2.
Утримуйте Win, натисніть Space двічі, відпустіть Win: має бути 3.
Натисніть і відпустіть Win + Space: має бути 2, а не фіксована мова.

МЕНЮ ЗНАЧКА
Правий клік по значку MRU Layout:
"Pause (default Windows switching)" повертає стандартну поведінку комбінації.
"Run at startup" вмикає або вимикає автозапуск через HKCU\...\Run.
"Exit" завершує процес і прибирає перехоплення клавіш.
Win окремо, Win + R/E/L, а також комбінації з Ctrl/Alt/Shift
цей скрипт навмисно не переназначає.

АВТОЗАПУСК
Окремо створювати ярлик більше не потрібно.
Меню "Run at startup" додає або прибирає запис у
HKCU\Software\Microsoft\Windows\CurrentVersion\Run.
При запуску Windows буде стартувати прихований процес PowerShell,
який викликає цей самий файл MRU-Layout.ps1.

ЩО ПРАЦЮЄ І ЩО ЗМІНЮЄТЬСЯ
Start.cmd запускає штатний Windows PowerShell із прихованою консоллю.
PowerShell компілює C#-код із MRU-Layout.ps1 через Add-Type, перевіряє
тестові сценарії історії і запускає обробник клавіш.
Постійно працює один додатковий процес PowerShell.
Скрипт не завантажує пакетів, не має мережевих запитів, не записує
натискання клавіш або введений текст.
Постійних змін немає, окрім необов'язкового запису автозапуску в HKCU Run.
Обробник отримує клавіатурні події для розпізнавання комбінації;
замість тексту він зберігає лише порядок ідентифікаторів розкладок у RAM.
Історія починається після запуску і не зберігається між перезапусками.
Спочатку невідомі за давністю мови беруться в порядку Windows.
Немає власного екранного меню; активну мову показує індикатор Windows
і підказка значка MRU Layout.

ПОЛІТИКА POWERSHELL
Start.cmd передає -ExecutionPolicy Bypass лише новому процесу PowerShell.
Постійна політика виконання не змінюється, Set-ExecutionPolicy не викликається.
Корпоративні політики можуть усе одно заборонити запуск.
Не вимикайте Defender, SmartScreen чи корпоративний захист заради цього скрипта.
Код повністю доступний у файлі MRU-Layout.ps1.

ОБМЕЖЕННЯ І ЧЕСНИЙ СТАТУС ПЕРЕВІРКИ
Перевірки логіки історії вбудовані та виконуються після компіляції
під час запуску. Вони не замінюють перевірку клавіатурного перехоплення
та сумісності з конкретними програмами у Windows.

Windows може блокувати обмін із програмами, запущеними від адміністратора.
За такого блокування можливе звичайне, а не MRU-перемикання, або попередження.
Окремі програми можуть ігнорувати WM_INPUTLANGCHANGEREQUEST.
У такій програмі використайте індикатор мови або "Pause" в меню скрипта.
Підтримку екрана входу, UAC, віддалених сеансів, ігор та складних
IME/TSF-профілів (на відміну від звичайних клавіатурних розкладок) не гарантовано.

Якщо у Windows ввімкнено окрему розкладку для кожного вікна, фокусування
іншого вікна теж може змінити мову. Скрипт не вимикає цю опцію.

ЯКЩО НЕ ЗАПУСТИЛОСЯ
У терміналі, відкритому в папці скрипта, виконайте:
.\Start.cmd debug
Консоль залишиться видимою і покаже помилку компіляції чи запуску.

ВИДАЛЕННЯ
Оберіть "Exit", вимкніть "Run at startup" (якщо вмикали),
видаліть папку з цими файлами.

ОНОВЛЕННЯ 1.1.2
На "холодному" старті, коли MRU-історії ще немає, використовується
природний порядок розкладок Windows. Поточна мова стає початком циклу.
Додано резервне визначення порядку через профіль користувача та fallback
на стандартний Windows-перемикач, якщо іншу розкладку не вдалося визначити.

ОНОВЛЕННЯ 1.1.3
Виправлено ініціалізацію на старті: глобальний клавіатурний hook тепер
встановлюється лише після фактичного запуску WinForms message loop.
Це прибирає залежність від першого відкриття tray-меню або списку значків.
